# Смена / Photosmena

Готовая сборка интерфейса: **https://miheenko-i.github.io/photosmena/**.

Нажмите «Подключить студию» и оставьте авторизованное окно сервера открытым. Персонажи, библиотека и генерации работают через защищённый сервер: https://smena-photo-studio.miheenko.chatgpt.site/.

В этом репозитории только опубликованные файлы интерфейса. Исходники, сервер, API-ключи и пользовательские данные хранятся отдельно. Клиентские скрипты доступны браузеру, source maps не публикуются.

Публикация: GitHub Pages, `main` → `/ (root)`.
